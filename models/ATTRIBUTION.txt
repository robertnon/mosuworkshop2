Obtained via the dualsense-studio project by SafaElmali
(https://github.com/SafaElmali/dualsense-studio), file controller/dualsense.glb.
That project's controller/controller-view.js was also used as the reference for
the per-material metalness/roughness values in controller-3d-ds5.js.

Credit is displayed in the bottom-right corner of the 3D preview box as
